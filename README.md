# 📅 Aplikasi Absensi Kehadiran (Attendance Management System)

Sebuah sistem pencatatan kehadiran digital yang dirancang untuk mempermudah pelacakan waktu masuk dan keluar secara efisien, akurat, dan transparan.

## ✨ Fitur Utama
* **Clock-In & Clock-Out:** Pencatatan waktu kehadiran harian secara *real-time*.
* **Riwayat Kehadiran:** Menampilkan data rekapitulasi absen secara berkala.
* **Antarmuka Intuitif:** Desain UI yang mudah dipahami oleh pengguna untuk mempercepat proses absensi.

## 🛠️ Teknologi yang Digunakan
* **Frontend:** React
* **Backend:** Java
* **Database:** DynamoDB
* **Desain UI:** Figma

## 🚀 Cara Menjalankan Proyek Lokal
1. Clone repositori ini:
   `git clone https://github.com/ellsyahreza-web/nama-repo-absensimu.git`
2. Buka folder proyek menggunakan VS Code.
3. Instal semua dependensi yang dibutuhkan.
4. Jalankan aplikasi melalui terminal.
